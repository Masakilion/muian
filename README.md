# 無為庵(むいあん)

老子(『道徳経』)を主答者、荘子・エピクロス・ショーペンハウアー・ハイデガー・スピノザを副答者とする哲学相談室アプリです。悩みや問いを書くと、テーマを自動判定し、まず老子が『道徳経』の原文に基づいて答え、続けて関連の深い2人の哲学者が別の視点から応答します。残り3人にはボタンひとつで追加の意見を聞くことができます。

**公開ページ**: https://Masakilion.github.io/muian/

## 使い方

1. 「相談する」タブで、悩みや問いを自由に書くか、12種類のテーマボタンから選びます。
2. まず老子が『道徳経』の原文・書き下し・現代語訳とともに答えます。
3. 続けて、そのテーマに関連の深い2人の哲学者が別の角度から応答します。
4. 残り3人には「◯◯にも聞く」ボタンで追加の意見を呼び出せます。
5. 「哲学者たち」タブで6人のプロフィールを、「概念事典」タブで22の重要用語を、「比較表」タブで6人の思想を7つの軸で比較した表を見ることができます。

## 登場する哲学者

- **老子**(主答者) ― 道家思想の始祖。『道徳経』
- **荘子** ― 老子の思想を寓話で発展させた継承者。『荘子』
- **エピクロス** ― 静的快とアタラクシアを説いた古代ギリシャの哲学者
- **ショーペンハウアー** ― 意志の哲学、厭世主義。『意志と表象としての世界』
- **ハイデガー** ― 現存在の実存分析。『存在と時間』
- **スピノザ** ― 神即自然、理性による自由。『エチカ』

## 技術構成

Vanilla HTML + CSS + JavaScript のみで構成された、依存関係のない単一HTMLファイルです。サーバーもビルドツールも不要で、`muian.html` をブラウザで開くだけで動作します。
